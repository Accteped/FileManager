# 文件分类系统
## 当前版本：demo0.0.1

*功能介绍*
~~~
1.选择文件夹，将当前文件夹的文件按后缀名分为
         文本文件: [".txt", ".md"],
         图片: [".jpg", ".png"],
         文档: [".pdf", ".xlsx", ".ppt", ".pptx", ".doc", ".docx"],
         视频&音频: [".mp4", ".avi", ".mov", ".mp3", ".wav", ".flac"],
         压缩文件: [".zip", ".rar", ".7z"],
         代码文件: [".py", ".js", ".html", ".css", ".c", ".cpp", ".php"]
2.移动之后可以选择撤销当前操作
~~~

### 本地部署
*使用之前要安装依赖库*

~~~
pip install PySide6
python Qt_UI.py
~~~
